# Crosswalk: paper output → script → file

Every figure and table in the accepted manuscript and its Supplementary Information, mapped
to the script that produces it and the file it is written to. Output filenames in the
replication package match the numbering used in the paper.

Reference documents: `sccp_main_anon_R2_clean.docx`, `sccp_SI_anon_R2_clean.docx`.

Scripts are numbered in execution order. `run.do` executes them in that order.

**Tables S18 to S21 are not produced by a public run.** They come from `01_clean_data.do`,
which requires the raw household survey and is therefore shipped for inspection but not
executed by `run.do`. The tables a replicator can produce from the distributed data are
S1 to S17 and S22 to S27, that is 23 of the 27.

Tables S18 and S19 come from `esttab` and are written as `.rtf`. Each file holds two panels,
intrinsic motivations then extrinsic motivations, matching the SI layout.

Tables S11, S20 and S21 come from commands (`rbounds`, `factor`) that print their results
rather than returning them in a form `esttab` can consume. Previously they were transcribed
by hand from the Stata log. They are now captured to dedicated text files
(`tableS11_rosenbaum_bounds.txt`, `tableS20_S21_factor_agency.txt`), so the numbers in the SI
are traceable to a file rather than to a scrollback buffer.

## Known discrepancies against the published SI

Documented here so replicators are not surprised when package output differs from the PDF.

1. **Figure S6 (Leakage to GNP), panels A and B.** In the published version the axis labels,
   legend and panel title read "≤5km" / ">5km", but the underlying variable `close_to_sccp` is
   defined at 2 km. The estimates are unaffected; only the labels were wrong. The package
   produces the figure with correct 2 km labels. The 5 km specification is estimated separately
   and reported in Table S10.

2. **Figure S3 (Common support and bias reduction, Hansen 20%), panel E.** The published
   version combined the bias-reduction plot from the miombo/own-classification matching run
   rather than the Hansen 20% run, because `gr combine` referenced a stale filename. The
   package produces panel E from the Hansen 20% run, as the caption states. Panels A–D are
   unaffected.

3. **One more subgroup table than the SI reports.** The code produces six subgroup tables;
   the SI includes five, S23 to S27. The sixth, subgroup effects on extrinsic motivations,
   ships as `results/diagnostics/diag_extrinsic_motivations.rtf`. An earlier draft cited
   "Tables S23-S28"; that cross-reference was corrected to S23-S27 at proof stage.

## Analyses removed from the package

Present in the working code but not in the accepted paper, and therefore not shipped:

- **Instrumental-variable / 2SLS estimation** of GNP employment using distance to Nhambita as
  an instrument, plus the associated bivariate-probit models and bootstrap. Removed during the
  first revision after the exclusion restriction was judged indefensible. The employment
  pathway is carried descriptively by Figure 8.
- **Placebo tests** assigning fake treatment dates in 2001 and 2002. Not reported in the paper.
- **Hansen 10% canopy threshold** branch (matching and DiD). The paper uses 20% as the primary
  threshold and 30% as robustness; 10% appears nowhere.
- **Inverse-probability-weighted (IPTW) specifications** and a synthetic DiD variable, both
  abandoned during development.
- **Village-level forest-cover analysis** and the TMF (JRC Tropical Moist Forest) coverage
  feasibility check, neither of which reached the paper.
